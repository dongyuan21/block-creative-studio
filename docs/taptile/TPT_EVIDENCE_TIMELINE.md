# TapTile 关键证据时间点

时间点来自无水印原版成片，精度用于定位与复核，不作为逐帧导演定时的最终标定值。

| 源组 | 约时间 | 可观察证据 | 支持的规则 |
|---|---:|---|---|
| `tpt811` | 2–5 s | 小熊、椅子依次进入顶部槽位；第三张椅子后同面组碎裂 | 同面归组；三张消除 |
| `tpt811` | 16–18 s | 点击被覆盖区域后出现 `Focus on the Top Tiles!` | 被上层覆盖的牌不可点 |
| `tpt811` | 39–45 s | 槽位达到 6/7，出现 `Only 1 Slot Left!` | 7 槽；6 槽预警 |
| `tpt760` | 2–9 s | 密集牌堆连续进入槽位并多次三消，棋盘其他牌不坠落 | 密集层级也复用同一槽位规则；无重力 |
| `archive04` | 0 s | 顶部目标为 `0/9` | 存在独立收集目标 |
| `archive04` | 8–10 s | 目标进度约 `1/9 → 3/9`，槽位中同时出现绿色目标牌 | 目标选中计数与三消可并行 |
| `latest_competitor` | 0–4 s | 金币由 `0/50` 变为 `10/50`，伴随大金币表现 | 金币是独立计数/特殊物件事件 |
| `latest_competitor` | 55–56 s | 心形 `9/9`、金币仍为 `40/50`，棋盘清空并进入胜利彩屑 | 不应把金币 `50` 武断设为硬胜利条件 |
| `tpt971` | 5–7 s | 点一个牌面后，分散在棋盘上的同面副本发光聚合并一起消失 | 点一张自动清同面集合；无槽位 |
| `chain_clear` | 20–29 s | 三张相同水果先在原位高亮，随后变为孔洞；下方牌不补位 | 原位手选三张；固定孔洞；无重力 |
| `big_flower` | 0–15 s | 点一朵花后同类花聚集并爆开，画面没有统一牌体边框 | 装饰性集合清除；不属于固定牌面替换 |

建议后续拿到原始交互录屏后再增加：失败样本、错误点击样本、道具使用、每次飞行起止帧和音频同步点。
