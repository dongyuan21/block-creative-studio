# 尚未解决的证据项 v2

以下项目在整段 13,546 帧扫描后仍不能仅凭单条录像可靠确定。代码和文档必须继续显式标记为 `unresolved`，不能用“看起来合理”的公式冒充参考产品规则。

## 1. 计分

- 放置阶段确认存在按新单元逐点增加，但所有特殊情况尚未穷尽。
- 清除格内 `5` 与 `9` 的选择条件不明确。
- `33 / 66 / 99 / 173 / 222 / 296 / 327 / 393 / 443 / 491 / 981 / 2354` 等浮动值与顶部总分的准确映射不明确。
- 多行、多列、交叉清除的基础分、倍率和 Combo 加成无法由单局唯一反推。
- `Unbelievable +300` 是固定奖励、等级奖励还是某种事件奖励，仍需受控实验。

## 2. Praise 与 Combo

- 六级评价词的严格排序和阈值尚未完全证明。
- Praise 由一次清除格数、行列数、连续清除、Combo 还是综合评分触发，仍不明确。
- Combo 的延续窗口、断连条件和最终 `Combo 14` 定义尚未确定。
- Praise、Combo 与浮动分数的排队/抢占规则尚未完全标定。

## 3. 候选生成

- 三块候选的形状分布、颜色分布与逐格牌面分配规则未知。

- 新三块刷新动画的精确事件起点与 Piece 可交互时点仍需逐次标定。

## 4. 交互

- 录像中没有足够清晰的非法释放案例，非法落点颜色、震动或回弹属于系统必需但参考证据不足。
- 拾取放大、上移、吸附和落定曲线已有近似范围，尚未完成逐帧曲线拟合。
- 触摸点本身未显示，因此真实手指位置只能由被拖 Piece 的相对运动推断。

## 5. 牌面纹样

- 已确认至少存在扶桑花、单叶、龟背竹、多瓣花和玫瑰轮廓。
- 颜色与纹样是否固定一一对应，还是存在多个随机组合，尚未从单局完全证明。
- 紫色与玫红是独立颜色，但两者对应的花纹家族仍需更多静态样本校准。

## 6. 新最高分

- 已确认超过原最高分后，左上数字随当前分数继续更新，并出现独立横幅。
- 横幅出现的精确延迟、持续时间、是否只出现一次以及后续再创新高是否重复显示，当前录像不足以证明。

## 7. 音频

本轮只完成视觉全帧审计。源视频包含 AAC 双声道音轨，但 placement、clear、praise、combo、tray refresh 和 endgame 声音尚未完成事件级拆分。音频将在共享 Event Index 上单独建立 `AUDIO_EVENT_LINEAGE`。

## 8. 固定机位影视后端

- 参考视频本身不能证明原始内容使用正交相机、长焦透视或纯 2D 合成。
