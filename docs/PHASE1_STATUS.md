# 当前实现状态

## 版本定位

`0.2.0-alpha.1` 是第一版 **reference-first 2D baseline**，不是“一比一复刻完成版”。

## 已落地

- 对用户提供的 225.833 秒真机视频完成第一轮分段观察、布局测量和原子目录。
- 参考 1064×1788 画布、顶部 HUD、912×912 棋盘、8×8 格槽和三个候选区。
- 新增 `reference-2d` 默认渲染后端；旧 Three.js 后端保留为实验能力。
- 将 2D 方块拆成逻辑格、逐格颜色、材质和牌面纹样四部分。
- 候选块支持逐格多色；棋盘落子会保留每个单元自己的颜色。
- 拖拽拾取支持候选尺度到棋盘尺度的放大，以及参考视频式上移。
- 合法落点预览和完整行/列预消除填充已分别建模。
- 落子反馈加入逐格计分阶段、发光和拇指覆盖。
- 清除演出加入线底、方向扫光、逐格 5/9/拇指、星屑、消散、评价词、Combo 和边框余辉。
- Game Over 参考继续卡片已形成第一版绘制骨架。
- 导出器可按项目选择 reference 2D 或实验 3D 后端。
- 玩法、Replay、Schema 和项目导入已支持多色候选块与新 2D StyleSpec。

## 已确认但尚未完全实现

- 候选块刷新时的独立粒子/辉光阶段。
- 下一次拖拽与上一轮评价、Combo、计分和环境余辉的完整异步重叠。
- 大型心形、花朵等高强度认可反馈的状态选择。
- 终局显示的 Combo 不是简单等于当前连续清除变量，需要单独建模。
- 逐动作节奏和各个 VFX 原子的可视时间线编辑。

## 未解决，不应声称一致

- 精确清除奖励公式和格内 5/9 的选择规则。
- Nice / Great / Fantastic / Unbelievable 的严格触发阈值。
- Combo 延续、中断及 Game Over 标题的准确规则。
- 候选块生成概率、难度控制和保底。
- 所有字体、图标轮廓、颜色和动画时长的像素级标定。
